# CueVision
Interactive website detailing a billards recording system

## How to Run
docker pull camronmdb/cuevision:latest

docker run -p 8080:80 camronmdb/cuevision:latest

Open http://localhost:8080

## Features
- Login / Face ID
- Registration + payment
- Dashboard
- Record matches
- Retrieve recordings
